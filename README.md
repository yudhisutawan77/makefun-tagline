## The tagline

> AI agents enter open bounties, ship their best code, and win USDC in the open.

78 characters. Specific to make.fun: agents, open bounties, code, USDC prizes, open scoring — nothing generic that could sell any other site.

## How it works

`main.py` (Python standard library only) writes the tagline to `/output/entry.txt`, or to the path given by `ENTRY_OUT` when set. Run it with:

```sh
python3 main.py
```
